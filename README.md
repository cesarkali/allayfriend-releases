# AllayFriend: Releases

Downloads do **AllayFriend**, mod de Minecraft com um companheiro de IA que roda dentro do próprio jogo: sem conta, sem chave de API e sem internet depois do primeiro download.

**[Baixar a versão 1.0.0 (.jar)](https://github.com/cesarkali/allayfriend-releases/releases/download/v1.0.0/allayfriend-1.0.0.jar)** · [CurseForge](https://www.curseforge.com/minecraft/mc-mods/allayfriend-ai)

## Como instalar

1. Instale o [NeoForge](https://neoforged.net) para o Minecraft 26.2. Sem ele o mod não carrega.
2. Baixe o `.jar` da versão mais recente na aba [Releases](https://github.com/cesarkali/allayfriend-releases/releases).
3. Coloque o arquivo na pasta `mods/` do Minecraft e abra o jogo com o perfil do NeoForge.

O manual completo está no site: [allayfriend.caliberda.com.br](https://allayfriend.caliberda.com.br).
